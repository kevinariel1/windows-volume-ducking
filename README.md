# How to Use
1. Download the `ducking.exe` from the releases/folder.
2. Double-click to run. (Note: It runs in the background with no console window).
3. To stop it, find `ducking.exe` in your **Task Manager** and select **End Task**.

Notes : Add a shortcut to this `.exe` in your Windows `shell:startup` folder so your music is always smart from the moment you boot up.
